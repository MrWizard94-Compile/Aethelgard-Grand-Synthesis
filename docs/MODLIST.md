## Recommended additions (not in the original concept)

- **Embeddium + Oculus** — rendering performance + shaders (Forge equivalents of Sodium/Iris).
- **FerriteCore + ModernFix** — memory + load-time optimization for a pack this size.
- **Jade** + **JEI/REI** — tooltips + recipe viewing (required QoL for a kitchen-sink pack).
- **Citadel** — dependency for Alex's Mobs.

## Notes

- Progression intent: Create/Botania (early) → AE2 gated by exploration (mid) → Mekanism fusion gated by Cataclysm boss drops (late). Wire cross-mod recipes via **KubeJS** if you want the "synthesis" to be enforced.
